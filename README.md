# Pandas Advanced Practice | Data Analysis with Python

A hands-on Pandas learning project focused on developing practical data analysis and problem-solving skills through real-world datasets and progressively challenging analytical exercises.

Rather than simply learning Pandas functions, this repository focuses on applying them to solve analytical problems, calculate meaningful KPIs, compare performance, and extract insights from structured data.

## Project Overview

This project contains intermediate-level Pandas exercises performed across four datasets covering cricket analytics and movie analytics.

The primary objective is to strengthen data manipulation, aggregation, filtering, sorting, and analytical thinking using Python's Pandas library.

## Datasets Explored

### 1. IPL Matches Dataset
**DataFrame:** `ipl`

Analytical exercises:
- Team-wise match wins and performance.
- Matches played versus matches won.
- Overall team win percentages.
- Season-wise team performance.
- Toss wins and toss-to-match-win conversion.
- Team consistency analysis.

### 2. IPL Deliveries Dataset
**DataFrame:** `ipld`

Analytical exercises:
- Batsman performance analysis.
- Total runs, boundaries, and balls faced.
- Batsman strike rate calculations.
- Total innings played.
- Bowler economy rate.
- Death-over bowling performance.
- Bowling average and bowling strike rate.
- Multi-metric player performance comparisons.

### 3. Movies Dataset
**DataFrame:** `movies`

Analytical exercises:
- Genre-wise movie analysis.
- Average and median IMDb ratings.
- Highest and lowest ratings by genre.
- Movie count by genre.
- Multi-genre analysis using string splitting and row expansion.

### 4. IMDb Top 1000 Dataset
**DataFrame:** `imdb`

Analytical exercises:
- Rating-based movie filtering.
- Movie ranking using ratings and votes.
- Sorting and conditional selection.
- Year-wise movie performance analysis.
- Vote-based comparisons.

## Getting Started

Clone the repository:

```bash

```

Navigate to the project:

```bash
cd pandas-advanced-
```

Install the required libraries:

```bash
pip install pandas jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook and execute the cells.
